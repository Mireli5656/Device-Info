📱 Device Info 

A simple, privacy-friendly web tool that shows information about your device and browser.

Everything runs directly in your browser. No account, backend, database, or tracking is required.

✨ Features 
📱 Device type 
💻 Operating system 
🌐 Browser 
🔎 User Agent 
🖥️ Screen resolution 
📐 Window size 
🔢 Device pixel ratio 
⚙️ CPU cores 
💾 Device memory 
👆 Touch support
📡 Network information 
🌍 Browser language 
🕐 Timezone 
🍪 Cookie status 
🚫 Do Not 
Track status 
🌐 Online/offline status 🔄 Refresh information 

Some information depends on browser support and may show as Not available.

🚀 How to Use Open Device Info. The page automatically detects the available device and browser information. Browse the different sections to see the results. Click Refresh Information if you want to update the values. 🔐 Privacy 

Device Info is designed with privacy in mind.

No account required No backend No database No tracking No external API No information is uploaded to a server 

All information is collected locally using browser APIs and displayed on the page.
